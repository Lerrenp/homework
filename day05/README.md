# Day 05 - 「此刻」图文社区产品原型

## 作业目标

根据课堂综合项目要求，完成「此刻」图文分享社区的移动端和电脑端高保真页面原型。

## 核心交付

| 页面 | 移动端 | 电脑端 |
| --- | --- | --- |
| 首页 | `01_首页.png` | `01_首页_电脑版.png` |
| 发布页 | `02_发布页.png` | `02_发布页_电脑版.png` |
| 笔记详情 | `03_详情页.png` | `03_详情页_电脑版.png` |
| 个人中心 | `04_个人中心.png` | `04_个人中心_电脑版.png` |
| 登录注册 | `05_登录注册.png` | `05_登录注册_电脑版.png` |

## 设计要点

- 首页包含分类筛选、图文卡片流、点赞信息和响应式导航。
- 发布页包含图片上传、标题、正文、话题、可见范围和草稿处理。
- 详情页包含多图内容、作者信息、点赞、收藏和评论区。
- 个人中心包含用户资料、作品、收藏和点赞三个列表。
- 登录注册包含手机号、短信验证码、密码登录和注册流程。
- 移动端使用底部导航，电脑端使用左侧导航和多列内容布局。

10 张原型图均已提交，覆盖 5 个核心页面的移动端与电脑端状态，可作为后续数据库、接口和前端实现依据。
